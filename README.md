# 🌍 Impact Analysis of the Russia–Ukraine War Using Data Analytics

## 📌 Project Overview

This project analyzes the global impact of the Russia–Ukraine War using data analytics techniques. The objective is to understand how the conflict affected economic indicators, energy markets, commodity prices, trade patterns, inflation, and other socio-economic factors.

Using Python-based data analysis and visualization tools, the project explores trends before and after the conflict to uncover meaningful insights and support data-driven decision-making.
